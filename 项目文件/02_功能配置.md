# 甲丁智能体 (Human-Agent) 系统功能详细说明

## 核心业务：车间数字化工作台 (Dashboard)

为班组长量身定制的一站式生产调度面板。

### 1. 基础信息概览 (Header)
直观展示当前车间最关键的四大基础指标：
- **所属班组**：当前班次及基本信息。
- **人员出勤**：应到/实到人数。
- **车间环境**：温湿度及运行状态。
- **设备状态**：总设备/维修中设备数量。

### 2. 异常预警雷达 (Alerts)
采用高亮跑马灯形式，实时滚动播报五大关键异常：
- **人员超时**：员工加班超过合规标准。
- **设备异常**：需要例行保养或突发故障。
- **排产变动**：紧急插单任务提醒。
- **品质异常**：工序加工参数偏差等。
- **报废异常**：物料损耗超出阈值。

### 3. 日期筛选待派工单列表 (Work Orders)
应对大量工单，支持灵活过滤：
- **按日期筛选**：默认展示当天的生产工单，支持日历筛选。
- **状态流转限制**：列表**仅**展示未派工 (PENDING/UNASSIGNED) 的工单。**一旦派工下单，工单流转为 DISPATCHED，不再出现在派工列表中**，避免重复派工。

### 4. 智能派工预览与调整 (Dispatch Dialog)
点击具体工单的“智能派工”后，进入核心决策弹窗：
- **AI 推荐名单**：系统基于技能、排班等后台算法（此处展示模拟结果）预先勾选推荐人员，并打上推荐标签和理由。
- **人工微调 (穿梭框)**：班组长可自由将左侧可用人员移至右侧已派发名单中。
- **一人多单**：系统允许多个工单指派给同一个人（一人负责多台机或多道工序属于常见场景）。

### 5. 操作与推送联动 (Actions)
- **确认派工**：提交调整后的人员名单，工单状态流转。
- **打印派工单**：触发浏览器端局部打印功能，直接输出纸质单据。
- **钉钉推送**：向车间班组群或个人（例如：15957270693）定向推送具体的工单任务和生产数量。


## 新增业务：角色工作台分离与数据维护 (Data Maintenance)

系统已根据登录角色实现严格的路由与菜单隔离：
- **班组长 (TEAM_LEADER)**：仅可访问“生产工作台 (Dashboard)”。
- **系统管理员 (SYS_ADMIN)**：仅可访问“系统设置 (Settings)”，支持全局系统参数管理。
- **数据管理员 (DATA_ADMIN)**：仅可访问“数据维护 (Data)”，进行主数据管理。

### 1. SAP 延伸主数据
由于本系统作为 SAP 在执行层的延伸，建立了以下 6 大对标模块：
- **物料档案**：隐藏了手工新增按钮（需从 SAP 同步），补充了 有效起始期、货架寿命、安全库存 等十余项明细指标。
- **物料组档案**：维护分类与 SAP 的对照码。
- **不良原因档案**：本地不良代码与 SAP 字典对照。
- **工艺路线档案**：管理 SAP 下发的生产路径版本。
- **工序档案**：管理具体的生产工序动作，**并补充了绑定BOM (bound_bom_code) 的能力，由工序主动拉取并分配物料组件**（对齐 SAP 的组件分配 Component Allocation 逻辑）。
- **BOM 档案**：呈现产品、子件及用量清单，支持 替代物料同行号 的逻辑映射。

### 2. APHR 延伸主数据
系统通过独立页面作为 APHR 数据的查询抓手：
- **员工档案**：从 APHR 抓取，仅供查看员工的基本信息、所属车间、健康证有效期、上岗证有效期及技能矩阵。
- **车间档案**：支持与 SAP 工作中心 (Work Center) 的 N 对 N 映射。

### 3. 生产订单留痕
- **生产订单记录**：沉淀所有从 SAP 同步的生产订单及本地流转情况，支持时间检索和未来导出的扩展。

以上所有基础数据均接入统一的后端分页查询接口，保证海量数据加载性能。
