# 甲丁智能体（一期）- 开发任务分解

开发任务按功能模块和前后端职能进行拆解，供项目组研发排期使用。

## 1. 基础架构与基础设施搭建 (Task Group 1)
- **[后端]** 数据库设计与建表（包含用户角色、订单、加班申请表、系统配置表、临时流水表）。
- **[后端]** FastAPI 框架初始化，配置 SQLAlchemy，编写全局异常处理、鉴权中间件、日志模块。
- **[前端]** 初始化 Vue 3 工程，集成 ECharts/DataV 组件库，配置路由拦截器与 Axios。
- **[前端]** 配置不同身份（生产岗/管理岗）登录后的路由自适应跳转与权限 Layout。
- **[前端]** 实现明亮/暗黑两套UI主题切换（参考 `http://localhost:8099/`），并集成 `d:/dev/logo` 目录下的系统级Logo和品牌图标。
- **[后端/运维]** 端口管理：读取全局端口记录表，自动注册并分配两个可用端口（前端与后端各一），确保不与其他系统冲突。
- **[运维]** 源代码管理：初始化工程并推送到 Git 仓库 `https://github.com/AprilZB/Human-Agent`，配置定时自动备份机制。
- **[AI]** 确保 vLLM 双模型在 ThinkPad PGX 部署完毕并对外提供兼容 OpenAI 格式的 API 接口。

## 2. 核心场景：订单—人岗智能匹配推荐 (Task Group 2)
- **[前端-管理后台]** 订单信息手工录入与管理页面开发（工单管理 CRUD）。
- **[后端]** 开发数据预处理层，整合 APHR 考勤/技能数据进行候选人清洗。
- **[后端]** **开发规则引擎模块**，实现基于岗位标签匹配、连续上班天数过滤、加班上限过滤的核心算法。
- **[AI/后端]** 编写 Prompt 并对接 vLLM，将规则引擎的结构化结果转换为推荐文案，暴露 `POST /api/recommendation` 接口。
- **[前端-大屏]** 排产推荐确认看板开发（接收后端的卡片数据并允许主管拖拽调整或确认）。

## 3. 场景：排班/请假/考勤看板 (Task Group 3)
- **[集成]** 梳理并调试 APHR 的组织架构与考勤请假只读 API 接口。
- **[后端]** 开发考勤数据聚合接口，做一层数据转换与缓存，适配前端大屏需要的格式。
- **[前端-大屏]** 开发班组/车间维度的可视化图表看板（出勤率饼图、排班甘特图/表格、请假预警红名名单）。

## 4. 场景：加班申请审批流程 (Task Group 4)
- **[前端-大屏/移动端]** 开发加班申请单填写弹窗及班组长/个人累计加班报表视图。
- **[后端]** 开发加班申请合规校验接口（读取 `sys_config` 的加班上限进行拦截）。
- **[后端]** 实现简单状态机（待审 -> 初审 -> 终审 -> 归档）。
- **[集成]** 对接 `dingtalk-service`，在状态机扭转时给对应主管推送钉钉通知。
- **[集成]** 预留/占位开发回写外部加班系统的通用适配器（Adapter），一期暂时打桩（Mock）或支持 CSV 导出。

## 5. 场景：一线员工日评分 (Task Group 5)
- **[前端-大屏]** 开发员工日评分极简操作面板（头像列表、快速点击打分、备注文本框）。
- **[后端]** 提供评分暂存与转发接口。
- **[集成]** 梳理并调试 APHR 绩效体系写入 API。
- **[后端]** 实现重试与容错机制：当写入 APHR 失败时，在本地打分流水表中标记为失败，并支持后台手动触发重推。

## 6. 场景：生产数据记录 (Task Group 6)
- **[前端-管理后台]** 开发日产量、合格率、不良品类型与数量的手工录入表单。
- **[后端]** 提供生产数据 CRUD 接口。
- **[后端]** 架构上预留 SAP 接口定时任务同步机制（一期可暂时写空函数或 Mock）。

## 7. 联调、测试与部署准备 (Task Group 7)
- **[前端+后端]** 全链路集成联调，特别关注大屏按角色（主管 vs 班组长）的数据隔离验证。
- **[全栈]** 进行并发压测，特别是验证在排产推荐时 vLLM 接口的响应时延是否符合操作体感。
- **[实施]** 整理系统说明与操作手册，配合一线管理人员试跑。
