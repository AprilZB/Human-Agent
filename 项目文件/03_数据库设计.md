# 数据库设计文档 (Master Data & MES Structure)

当前数据库使用轻量级 MySQL 结构。

## 1. 基础工序与人员匹配

### 1.1 ase_process (基础工序表)
- process_code: 工序编码 (PK)
- process_name: 属性名称
- equired_skills: JSON格式的技能要求

### 1.2 异常报警表 (规划中)
- 规划建立针对 超时、设备、品质、报废、插单 的异常记录表。目前前端 Dashboard 采用系统级 Mock 数据直接呈现预警雷达。

## 2. 生产单流转

### 2.1 iz_production_order (生产订单表)
- 来源于 ERP，包含 plan_start_time (计划开始时间)。

### 2.2 iz_work_order (生产工单表 / 派工单)
- **status (状态流转)**:
  - PENDING: 默认状态，待处理。
  - UNASSIGNED: 人员未满编。
  - DISPATCHED: **已确认派工**。工单一旦变为此状态，前端待派工列表将自动将其隐藏，防止重复派工。
- created_at: 生成时间，前端使用此字段配合**按日期查询派工列表**。

### 2.3 	ask_personnel_assignment (工单人员分配表)
- work_order_code: 关联的具体工单。
- employee_id: 员工工号。**无唯一约束，允许同一员工在同一时间段内被分配到多个工单（支持一人多单场景）**。
- status: AI_RECOMMENDED (推荐) -> CONFIRMED (最终确认)。
