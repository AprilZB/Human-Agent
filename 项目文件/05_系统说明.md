# 甲丁智能体（一期）- 系统整体说明手册

## 1. 项目背景与产品愿景
**甲丁智能体** 旨在成为脉通智造科技医疗器械车间生产协同的“智慧大脑”。
针对车间排产面临的“人岗匹配靠经验、加班合规靠手算、异常状况难追溯”等痛点，一期建设聚焦于赋能**车间主管**与**班组长**，用数字化和AI手段替代手工记录，将“订单-人岗匹配-生产推荐”实现全流程系统化运作，确保生产安排既高效又符合医疗行业的严苛合规要求。

## 2. 适用用户及入口指引

本系统按业务属性区分前后台，且基于登录身份自动路由。

| 用户角色 | 核心使用场景 | 入口建议 |
| :--- | :--- | :--- |
| **班组长** | 查看本班考勤、录入员工日评分、代员工发起加班审批、处理日常排产 | **车间数字化大屏 / 车间操作站** (极简大字UI，直达操作) |
| **车间主管** | 确认跨组/跨区人岗匹配结果、审批加班申请、查看全局考勤 | **车间数字化大屏 / 钉钉推送端** (全局视野+快速审批) |
| **系统管理员 / 统筹员** | 录入初始订单信息、修改加班时长上限配置、手工补录生产数据 | **独立管理后台** (传统报表数据界面，配置中心) |

*(注：当前一期采用 APHR 账号登录，二期将全面接入企业 SSO 单点登录系统。)*

## 3. 核心业务操作导览

### 场景一：拿到新订单，该派谁干活？ (订单-人岗匹配)
1. **管理员**在后台录入订单及工种技能需求（未来此步骤由 SAP 同步）。
2. 甲丁智能体会后台运算（剔除请假、过滤疲劳人员、匹配相关技能）。
3. **主管/班组长**在大屏上查看 AI 推送的《排班建议名单》，系统会用白话文告诉你“为什么推荐他”。
4. **主管**在大屏上一键确认或微调，排班计划生成。

### 场景二：处理员工加班 (加班申请与审批)
1. 员工口头申请或**班组长**根据生产任务直接在大屏端点击“发起加班”。
2. 系统自动拦截不合规的加班请求（如超出月度36小时限制）。
3. 提交后，**车间主管**钉钉会收到推送卡片，主管点击通过。
4. 审批结束后，系统负责将加班流水同步给人事系统（APHR），一线人员无需再填纸质单。

### 场景三：每日下班前的收尾工作 (日常记录)
1. **日评分**：班组长通过大屏快速给组员今日表现打分（优秀/合格/不合格），有特殊情况可写短备注。点击提交后数据自动进入 APHR 绩效库。
2. **生产数据**：质检或班组长在后台简单登记今日该批次产品合格率及不良原因。

## 4. 后续演进规划 (二期展望)
在一期保证基础数据流通和流程跑通后，甲丁智能体将向**全员级企业智能体**演进：
- **对话式查询**：车间主管可以直接向大屏发问：“今天本科学历的数控操作工出勤几个人？”，AI将直接生成图表报表。
- **全面接口自动化**：彻底取消手工导入，所有加班流程与 SAP 生产排程全部实现无缝对接。
- **角色下放**：逐步开放给质量部、厂长等角色，甚至普通一线员工可以查询自己的积分和考勤。
